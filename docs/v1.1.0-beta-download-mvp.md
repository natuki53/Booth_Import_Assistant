# v1.1.0-beta ダウンロード管理機能 MVP設計書

## 概要

BOOTH Import Assistant v1.1.0-betaに、**ダウンロード管理機能のみ**を最小限で実装します。
まずはコア機能に集中し、段階的に機能を追加していくアジャイル開発アプローチを採用します。

## MVP（最小実装）の範囲

### 実装する機能（Phase 1）
1. ✅ 「ダウンロードのみ」ボタンの追加
2. ✅ ZIPファイルの保存（ブラウザの元ファイル名を保持）
3. ✅ 保存済みファイルの自動判定機能
4. ✅ ボタンの自動切り替え（保存済みがある場合「DL & インポート」→「インポート」）
5. ✅ 保存済みZIPファイルからの直接インポート機能

### 後回しにする機能（Phase 2以降）
- ファイル管理タブ
- ディスク使用量表示
- キャッシュ管理
- ファイル削除機能
- 詳細なファイル情報表示

**実装の詳細**:
```csharp
private void DrawAssetInfo(BoothAsset asset)
{
    EditorGUILayout.BeginVertical();
    
    // タイトル（クリック可能、ホバー時に青く表示）
    DrawClickableTitle(asset);
    
    // 作者（改行対応）
    GUIStyle authorStyle = new GUIStyle(EditorStyles.miniLabel);
    authorStyle.wordWrap = true;
    GUILayout.Label("作者: " + asset.author, authorStyle);
    
    // 区切り線（作者とダウンロード状況の間）
    EditorGUILayout.Space(5);
    Rect dividerRect = EditorGUILayout.GetControlRect(false, 1);
    GUI.Box(dividerRect, GUIContent.none, GUI.skin.horizontalSlider);
    EditorGUILayout.Space(5);
    
    // ダウンロード状態セクション（新規追加）
    DrawDownloadStatus(asset);
    
    if (asset.installed)
    {
        GUILayout.Label("✅ インポート済み", EditorStyles.miniLabel);
    }
    
    EditorGUILayout.EndVertical();
}

private void DrawDownloadStatus(BoothAsset asset)
{
    // 全体のダウンロード状態
    var (downloaded, total) = presenter.GetDownloadStatus(asset);
    string statusText;
    if (downloaded == 0)
    {
        statusText = "ダウンロード状態：未ダウンロード";
    }
    else if (downloaded == total)
    {
        // すべてダウンロード済みの場合も、複数ファイルがある場合は (5/5) を表示
        if (total > 1)
        {
            statusText = $"ダウンロード状態：ダウンロード済み({downloaded}/{total})";
        }
        else
        {
            statusText = "ダウンロード状態：ダウンロード済み";
        }
    }
    else
    {
        // 一部ダウンロード済みの場合
        statusText = $"ダウンロード状態：ダウンロード済み({downloaded}/{total})";
    }
    GUILayout.Label(statusText, EditorStyles.miniLabel);
    
    // 選択中のファイルの状態（複数ファイルがある場合のみ表示）
    int totalFiles = asset.downloadUrls?.Length ?? 0;
    int avatarCount = asset.downloadUrls?.Count(url => !url.isMaterial) ?? 0;
    
    if (avatarCount > 1) // 複数アバターがある場合のみ表示
    {
        int selectedIndex = presenter.GetSelectedDownloadIndex(asset.id);
        bool isDownloaded = presenter.IsSelectedFileDownloaded(asset, selectedIndex);
        string selectedText = $"選択中のファイル：{(isDownloaded ? "ダウンロード済み" : "未ダウンロード")}";
        GUILayout.Label(selectedText, EditorStyles.miniLabel);
    }
    
    // マテリアルの状態（マテリアルがある場合のみ表示）
    var materialStatus = presenter.GetMaterialDownloadStatus(asset);
    if (materialStatus.Count > 0)
    {
        if (materialStatus.Count == 1)
        {
            string materialText = $"マテリアル：{(materialStatus[0] ? "ダウンロード済み" : "未ダウンロード")}";
            GUILayout.Label(materialText, EditorStyles.miniLabel);
        }
        else
        {
            List<string> statusParts = new List<string>();
            for (int i = 0; i < materialStatus.Count; i++)
            {
                string status = materialStatus[i] ? "ダウンロード済み" : "未ダウンロード";
                statusParts.Add($"{status}({i + 1})");
            }
            string materialText = "マテリアル：" + string.Join(" ", statusParts);
            GUILayout.Label(materialText, EditorStyles.miniLabel);
        }
    }
}

private void DrawAvatarDownloadButtons(BoothAsset asset, List<int> avatarIndices)
{
    int selectedIndex = 0;
    
    // 1行目: プルダウン（複数アバターがある場合のみ）
    if (avatarIndices.Count > 1)
    {
        selectedIndex = presenter.GetSelectedDownloadIndex(asset.id);
        // プルダウンメニューを表示
        // ... 既存のプルダウン実装
    }
    else if (avatarIndices.Count == 1)
    {
        selectedIndex = avatarIndices[0];
    }
    
    // 2行目: 本体用のボタン（保存済みファイルの有無で表示を切り替え）
    bool hasSavedFile = presenter.HasSavedFile(asset, selectedIndex);
    
    EditorGUILayout.BeginHorizontal();
    
    if (hasSavedFile)
    {
        // 保存済みファイルがある場合：「インポート」のみ表示
        if (GUILayout.Button("インポート", GUILayout.Height(26)))
        {
            presenter.ImportFromSavedFile(asset, selectedIndex);
        }
    }
    else
    {
        // 保存済みファイルがない場合：「ダウンロードのみ」と「DL & インポート」を表示
        if (GUILayout.Button("ダウンロードのみ", GUILayout.Height(26)))
        {
            presenter.DownloadOnly(asset, selectedIndex);
        }
        
        if (GUILayout.Button("DL & インポート", GUILayout.Height(26)))
        {
            presenter.DownloadAsset(asset, selectedIndex);
        }
    }
    
    // 「・・・」ボタン（常に表示）
    if (GUILayout.Button("・・・", GUILayout.Width(30), GUILayout.Height(26)))
    {
        presenter.OpenDownloadFolder(asset, selectedIndex);
    }
    
    EditorGUILayout.EndHorizontal();
}
```

## 実装フロー（最小限）

### 1. ダウンロードのみのフロー

```
ユーザー操作: 「ダウンロードのみ」ボタンクリック
    ↓
BoothLibraryPresenter.DownloadOnly()
    ├─ ダウンロードモードフラグを設定（このダウンロードは保存のみ）
    └─ Application.OpenURL(downloadUrl) (既存)
    ↓
【既存】bridge.jsがダウンロードフォルダを監視
    ↓
ZIPファイル検出
    ↓
【新規】ダウンロードモードを判定
    ├─ 「ダウンロードのみ」の場合:
    │   ↓
    │   DownloadManagerService.SaveDownloadedFile()
    │   ├─ 元のZIPファイルのパスを取得（ダウンロードフォルダから）
    │   ├─ AppData/Local/BoothImportAssistant/downloads/{商品ID}/に移動
    │   │   └─ 元のファイル名をそのまま保持（重複時は (1), (2) などを付与）
    │   └─ メタデータに保存
    │   ↓
    │   UI更新（ダウンロード済み表示）
    │   ↓
    │   完了（確認ダイアログは表示しない）
    │
    └─ 「DL & インポート」の場合:
        ↓
        【既存】extractAndImportZip()が実行
        ├─ ZIPファイルを展開
        ├─ .unitypackageファイルを検出
        └─ .unitypackageをBoothBridge/tempにコピー
        ↓
        【既存】FileWatcherServiceがtempフォルダを監視
        ↓
        【既存】PackageImportServiceが.unitypackageを検出
        ↓
        【既存】確認ダイアログ表示
        ├─ 「インポート」を選んだ場合: 既存のインポート処理
        └─ 「キャンセル」を選んだ場合: tempフォルダの.unitypackageを削除
```

**注意**: 
- **既存の仕様を変更**: 「ダウンロードのみ」の場合は確認ダイアログを表示せず、直接保存先に移動
- **「DL & インポート」は既存の仕様を維持**: tempフォルダに移動して確認ダイアログを表示
- ダウンロードモードフラグで、どのダウンロードが「保存のみ」かを識別する必要がある
- bridge.jsまたはUnity側でダウンロードモードを判定して処理を分岐する

### 2. 保存済みファイルからのインポートフロー（自動判定）

```
ユーザー操作: 「インポート」ボタンクリック（保存済みファイルがある場合）
    ↓
BoothLibraryPresenter.ImportFromSavedFile()
    ├─ 選択中のラベルに対応する保存済みファイルを自動検索
    └─ 保存済みファイルが見つかった場合
        ↓
DownloadManagerService.ImportFromDownloadedFile()
    ├─ 保存済みZIPファイルのパスを取得
    ├─ ZIPファイルを一時的に展開（os.tmpdir()/booth_temp_{timestamp}/）
    ├─ 展開先から.unitypackageファイルを検出
    └─ .unitypackageファイルをBoothBridge/tempにコピー
    ↓
【既存】FileWatcherServiceがtempフォルダを監視
    ↓
【既存】PackageImportServiceが.unitypackageを検出
    ↓
【既存】確認ダイアログ表示
    ├─ 「インポート」を選んだ場合: 既存のインポート処理
    └─ 「キャンセル」を選んだ場合: tempフォルダの.unitypackageを削除
    ↓
インポート完了（「インポート」を選んだ場合）
    ├─ 一時展開フォルダを削除
    ├─ tempフォルダの.unitypackageを削除（既存動作）
    └─ 元のZIPファイルは保持
```

**注意**: 
- 既存のPackageImportServiceのフローを再利用
- 保存済みZIPファイルから.unitypackageを抽出してtempフォルダにコピー
- その後は既存の確認ダイアログ→インポート処理の流れに従う

### 3. ボタンの自動切り替えフロー

```
アセット表示時
    ↓

    ├─ 選択中のラベルに対応する保存済みファイルを検索

    └─ 保存済みファイルがない場合: 
        ├─ 「ダウンロードのみ」→ 表示
        ├─ 「DL & インポート」→ 表示
        └─ 「・・・」→ 表示
```

### 4. 「・・・」ボタンの動作フロー

```
ユーザー操作: 「・・・」ボタンクリック
    ↓
BoothLibraryPresenter.OpenDownloadFolder(asset, downloadIndex)
    ↓
DownloadManagerService.OpenDownloadFolder(assetId)
    ├─ 保存先フォルダのパスを取得
    │   └─ AppData/Local/BoothImportAssistant/downloads/{商品ID}/
    └─ エクスプローラーでフォルダを開く
    ↓

    ├─ ブラウザでダウンロード
    └─ 同じファイル名で上書き保存
    ↓
FileWatcherServiceがファイル変更を検知
    ↓

    ↓
メタデータを更新
```

## データ保存

### 保存先
- Windows: `%LOCALAPPDATA%\BoothImportAssistant\downloads\{商品ID}\`
- Mac: `~/Library/Application Support/BoothImportAssistant/downloads/{商品ID}/`
- Linux: `~/.config/BoothImportAssistant/downloads/{商品ID}/`

### メタデータ
- 保存先: `AppData/Local/BoothImportAssistant/downloads_metadata.json`
- 形式: JSON配列

```json
{
  "version": "1.1.0",
  "downloads": [
    {
      "assetId": "商品ID",
      "label": "萌ちゃん用",
      "zipFilePath": "C:/Users/.../downloads/{商品ID}/avatar_package_v1.2.zip",
      "originalFileName": "avatar_package_v1.2.zip",
      "downloadedAt": "2024-01-15T10:30:00Z",
      "isMaterial": false
    }
  ]
}
```

### ファイル構造
```
AppData/Local/BoothImportAssistant/
├── downloads/
│   ├── {商品ID1}/
│   │   ├── avatar_package_v1.2.zip          ← 元のファイル名を保持
│   │   └── material_set.zip
│   └── {商品ID2}/
│       └── character_model_v2.0.zip
└── downloads_metadata.json
```

```csharp
public void DownloadOnly(BoothAsset asset, int downloadIndex)
{
    // Bridgeが起動していることを確認
    if (!bridge.IsBridgeRunning())
    {
        bridge.StartBridge();
    }
    
    // bridge.jsにダウンロードモードを通知
    string downloadUrl = asset.downloadUrls[downloadIndex].url;
    string label = asset.downloadUrls[downloadIndex].label;
    bridge.RegisterDownloadMode(downloadUrl, label, asset.id, "download-only");
    
    // ダウンロードURLを開く
    Application.OpenURL(downloadUrl);
}
```
